# Importação do RECALL v0.4 para GitHub

Este commit importa o código-fonte da versão 0.4 previamente preparado fora do GitHub.

- Framework: Tauri 2 + Svelte 5 + TypeScript + Rust.
- Banco de dados local: SQLite.
- Inclui uma prévia HTML separada para experimentar a interface.
- Arquivos de configuração locais, chaves e bancos de dados não devem ser publicados.
- O funcionamento nativo ainda não está validado; a primeira execução da CI identificará eventuais erros de compilação.

**Atenção:** os dados da prévia HTML não são os mesmos da versão desktop e não sincronizam automaticamente.
