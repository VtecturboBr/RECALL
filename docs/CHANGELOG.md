# Histórico

## v0.4 — Captura rápida
- Janela pequena para anotar ideias sem abrir a janela principal.
- Atalho global Ctrl+Shift+Espaço gerenciado em Rust no Windows.
- Botão Capturar na barra superior e opção na bandeja.
- Rascunho persistente; Esc preserva o texto; Ctrl+Enter salva.
- Captura em uma operação única de SQLite, notificando outras janelas.
- Prévia HTML com painel de captura de ideias (atalho funciona apenas com a aba aberta).
- Sem migração de banco e sem alteração da identidade visual simples.
